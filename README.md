# Agent Guardrails and Negative Tests

Standalone repository split from `agentic-commerce-platform`.

## What This Demonstrates

Prompt injection, unauthorized payment, hallucinated product, wrong price/inventory, PII, and coupon-abuse defenses.

This is a demo/training project. It uses mock grocery data only. It does not use real Kroger APIs, real payment APIs, real customer data, or secrets.

## Setup

```bash
make setup
```

## Run

```bash
make run
```

## Verify

```bash
make test
```
